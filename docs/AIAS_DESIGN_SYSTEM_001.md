# AIAS Design System 001

AIAS must look as capable as it is without hiding engineering complexity or manufacturing confidence. The design system is the shared implementation language for desktop, installer, ISO media, website, applications, documentation, dashboards and learning channels.

Version 0.1.0 introduces semantic dark/light tokens, typography, spacing, radius, motion, iconography and accessibility contracts plus a generated Qt Style Sheet. It deliberately does not rewrite the current interface yet. The following macrodelivery audits complete professional journeys and migrates surfaces in controlled slices.

The visual direction is technical, calm and high-contrast. Blue represents active engineering action; green, amber and red are reserved for status with accompanying text or iconography. Random third-party icons and scattered hardcoded colors are prohibited.

Project Director approval is required after rendered dark/light prototypes. Until that review, the palette is an implementation-ready candidate rather than a frozen brand decision.
