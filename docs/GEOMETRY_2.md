# Geometry 2.0 — Contrato semántico y frontera OCCT

El primer paquete verificable conserva el kernel geométrico determinista de AIAS y añade una fachada semántica estable. La disponibilidad de OCCT se detecta explícitamente; en el entorno actual no se declara integración de producción porque el runtime externo no está instalado.

La instalación o validación de licencias de OCCT requiere una decisión de dependencia externa y permanece como gate separado.
