# EXP-APPS-001 — Portafolio de aplicaciones y contratos compartidos

AIAS dispone de una base común para que escritorio, web, servicios y futuras aplicaciones complementarias compartan identidad, proyectos, capacidades, evidencia y seguridad sin fragmentar la fuente de verdad de ingeniería.

La implementación separa tres conceptos: una aplicación declarada mediante manifiesto; un proyecto referenciado mediante sobre canónico; y una decisión de acceso emitida por el broker. Solo aplicaciones validadas o liberadas pueden operar, cada operación exige un alcance explícito y las mutaciones usan revisión optimista.

No se afirma que existan cuentas públicas, nube productiva, aplicación móvil publicada ni autorización profesional. Esas capacidades requieren macroentregas y evidencia independientes.
