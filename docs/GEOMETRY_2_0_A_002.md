# GEOMETRY-2.0-A-002 — OCCT Proof of Concept

El probe aislado buscó el módulo `OCC` dentro del entorno virtual de AIAS. No está disponible. La decisión es conservar el backend nativo y no instalar OCCT automáticamente hasta completar compatibilidad de bindings, distribución y licencia.

Esto no bloquea el desarrollo de contratos Geometry, BIM ni Structural; únicamente impide afirmar una integración OCCT de producción.
