# AIAS Workspace 2.0 — W2-04

W2-04 introduces a searchable professional command catalog and an explicit status contract. Every command declares its stable identity, aliases, discipline, backing capability and real availability. Reference-only or unavailable commands remain discoverable but cannot execute, preventing the interface from exaggerating AIAS capabilities.

The status model permanently exposes jurisdiction, units, normative-pack state and professional review. An engineering release is authorized only when the normative pack is validated, the review is approved and a named professional reviewer exists.

The optional Qt palette consumes the same headless registry used by tests and future automation. The legacy command line now inherits the governed Design System instead of embedding an independent palette.
