# UNIVERSITY-FOUNDATION-001 — AIAS University

The foundation delivers a capability-linked course catalog, structured modules and lessons, deterministic assessments, progress controls and tamper-evident internal competency credentials. The first Spanish course teaches the Charter, Constitution, SDD, Engineering System and AES using canonical repository resources.

Credentials are explicitly `AIAS_INTERNAL_COMPETENCY`; they are not academic degrees, professional licenses or authorization to approve regulated engineering. Issuance requires completed content, a passing assessment and verified learner identity. HMAC signing keys remain external secrets and are never stored in the catalog or repository.
