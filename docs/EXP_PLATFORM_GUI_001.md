# EXP-PLATFORM-GUI-001 — AIAS Capability Center

El Capability Center convierte la infraestructura de entrega en una superficie observable de Workspace 2.0. Presenta componentes, paquetes, pruebas, puertas de calidad, instaladores, distribución y límites de confianza directamente desde la evidencia del repositorio.

La primera versión es deliberadamente de solo lectura: refresca evidencia y abre reportes, pero no ejecuta instaladores ni actualizaciones. La planificación de instalación permanece bloqueada mientras falte una firma editorial verificada; cualquier futura mutación exigirá confirmación, candidato íntegro y punto de recuperación.

La interfaz está disponible mediante el comando `CAPABILITY-CENTER`, con alias `CAPACIDADES` y `PLATAFORMA`, y mediante el panel estable `AIAS_CAPABILITY_CENTER`.
