# Sprint S2.08A — Constraint Engine

## Objetivo
Crear el primer núcleo paramétrico de AIAS: restricciones geométricas evaluables,
persistentes, detectables y resolubles.

## Capacidades
- Horizontal.
- Vertical.
- Parallel.
- Perpendicular.
- Coincident.
- Equal Length.
- Lock Point.
- Distance.
- Offset.
- Repositorio y almacén geométrico.
- Evaluación con tolerancia.
- Detección de conflictos.
- Reporte de solución.
- Eventos del motor.
- 120 pruebas automatizadas.

## Resultado esperado
120 pruebas específicas y 610 pruebas acumuladas.
