# ATO-000002 — Continuous Technology Observatory

ATO-000002 converts the observatory into a persistent operating loop. An approved source registry controls authority, cadence, HTTPS hosts and evidence strength. Fetching is injected behind a boundary so production adapters can use feeds or APIs while tests remain deterministic.

Every cycle records checked sources, admitted observations and duplicates. New observations receive reproducible multidimensional scoring, enter a technology radar and, when they qualify as giant-step opportunities, generate the complete AEC-000050 recommendation contract. External content is never executable and regulated adoption still requires SDD, security, legal and professional review.

The CLI accepts adapter-normalized JSON batches and writes an atomic persistent ledger. Scheduling can therefore be supplied by the AIAS operating environment while source-specific network parsing remains isolated outside the trusted scoring core.
