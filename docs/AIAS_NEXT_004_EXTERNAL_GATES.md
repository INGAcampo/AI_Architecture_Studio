# AIAS-NEXT-004 — Registro de gates externos

Este registro hace visible todo lo que AIAS no puede fabricar internamente: runtimes y licencias, fuentes normativas autorizadas, APIs de proveedores y aceptación profesional independiente.

Un estado `NOT_AVAILABLE` no es un error del contrato local; significa que la capacidad no puede presentarse como certificada o lista para uso profesional. La evidencia debe ser aportada por una autoridad adecuada y permanecer trazable.
