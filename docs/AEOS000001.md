# AEOS-000001

The AIAS Engineering Operating System is the dependency-aware control plane over existing systems. It registers CNS, PMO, Virtual Organization, Development Platform, Technical File, Security/Recovery and Intelligence services, then governs project transitions from INITIATED through OPERATING.

Every transition is sequential, idempotent, correlated, service-health checked and evidence gated. AEOS coordinates domain systems without replacing their professional, security or recovery controls.
