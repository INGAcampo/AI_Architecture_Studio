# ADR S2.07-001 — Workspace BIM unificado

**Decisión:** Outliner, materiales y familias comparten un modelo jerárquico común.

**Motivo:** simplifica búsqueda, selección, navegación y futura integración con IA.

**Consecuencia:** los catálogos siguen siendo servicios separados, pero la representación
visual se consolida.
