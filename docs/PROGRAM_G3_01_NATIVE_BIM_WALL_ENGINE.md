# G3.01 — Native BIM Wall Engine

Motor BIM nativo para muros inteligentes.

Incluye:

- WallType, WallLayer y CompoundStructure;
- WallInstance y WallProfile;
- generación geométrica 3D;
- aberturas hospedadas;
- uniones entre muros;
- cantidades netas y brutas;
- validación;
- regeneración paramétrica;
- API central NativeBimWallEngine.
