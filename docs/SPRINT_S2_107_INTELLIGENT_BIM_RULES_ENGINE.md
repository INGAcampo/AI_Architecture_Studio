# S2.107 — Intelligent BIM Rules Engine

Motor extensible para ejecutar reglas BIM sobre proyectos y elementos individuales.

## Capacidades

- Registro dinámico de reglas.
- Ejecución por proyecto, elemento o regla.
- Incidencias con severidad y recomendaciones.
- Estadísticas acumuladas.
- Reglas integradas:
  - ancho mínimo de puertas;
  - material faltante;
  - GUID duplicado;
  - nivel inválido;
  - propiedades obligatorias vacías.
