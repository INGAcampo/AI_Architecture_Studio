# ECP-000001B — Foundation Calculation Engine

This engine calculates transparent, traceable shallow-foundation demands:

- user-defined load combinations
- average, maximum and minimum bearing pressures
- eccentricities and middle-third kern status
- generic one-way shear demand
- generic punching demand
- generic flexural demand
- immediate elastic settlement estimate
- governing-combination identification
- JSON technical calculation package

Jurisdiction-specific resistance, reinforcement and detailing checks are intentionally delegated to AEKS code packs and require professional review.
