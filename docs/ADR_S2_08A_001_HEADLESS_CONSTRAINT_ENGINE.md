# ADR S2.08A-001 — Constraint Engine independiente de GUI

**Decisión:** las restricciones operan sobre geometría abstracta y referencias estables.

**Motivo:** permitir reutilización en CAD, BIM, estructuras, MEP, automatización e IA.

**Consecuencia:** la integración visual y los grips paramétricos se implementarán mediante
adaptadores posteriores.
