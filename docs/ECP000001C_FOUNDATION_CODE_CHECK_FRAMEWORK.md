# ECP-000001C — Foundation Code Check Framework

Provides a parameter-driven framework for:

- flexural reinforcement demand
- minimum reinforcement
- one-way shear capacity checks
- punching shear capacity checks
- cover checks
- minimum-thickness checks
- equation identifiers and traceability
- AEKS code-pack registry
- technical code-check reports

The included code pack is **REFERENCE_ONLY** and is intentionally non-normative. Regulated engineering use requires a separately verified official AEKS code pack for the applicable jurisdiction and mandatory professional review.
