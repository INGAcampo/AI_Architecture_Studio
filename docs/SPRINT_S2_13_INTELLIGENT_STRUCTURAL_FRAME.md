# Sprint S2.13 — Intelligent Structural Frame

## Objetivo
Crear la base estructural nativa de AIAS para columnas, vigas, riostras, perfiles,
materiales y modelo analítico lineal.

## Capacidades
- Column, Beam, Brace, Girder y Truss Member.
- Materiales estructurales.
- Perfiles I, H, C, L, RHS, CHS, rectangulares y circulares.
- Eje analítico 3D.
- Rotación local.
- Liberaciones y excentricidades.
- Longitud, área, volumen, masa y peso.
- Centro geométrico.
- Propiedades de inercia.
- Integración paramétrica.
- Integración con Regeneration Engine.
- Eventos.
- Ejemplo funcional.
- 120 pruebas.

## Resultado esperado
120 pruebas específicas y 1.570 acumuladas.
