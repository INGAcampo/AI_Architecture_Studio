# AEKS-ALIGN-001 — Executable Knowledge Completion

The existing AEKS already supplied identity, persistence, standards registry, ontology, search, import/export, versioning and traceability. This alignment adds the missing executable-knowledge boundary: approved knowledge requires a reusable license, attributable provenance, deterministic declarative mode and mandatory professional review.

The executor accepts arithmetic and comparison expressions only. Function calls, attributes, imports, mutation and unknown names are rejected by an AST allowlist. Inputs must exactly match the calculation contract, be finite and pass every validation rule. Each result records EKU identity/version, inputs, units, jurisdiction, review boundary and SHA-256 evidence. `EKU-000002` immediately demonstrates gross foundation bearing pressure as a generic reference calculation, not a jurisdictional design code.
