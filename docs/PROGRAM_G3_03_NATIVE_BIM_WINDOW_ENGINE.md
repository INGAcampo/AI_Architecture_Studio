# G3.03 — Native BIM Window Engine

Motor BIM nativo para ventanas inteligentes.

Incluye:

- familias y tipos;
- marcos y vidrios;
- ventanas fijas, abatibles, proyectantes y corredizas;
- montantes verticales y horizontales;
- geometría paramétrica;
- hospedaje automático en muros;
- creación automática de aberturas;
- cantidades térmicas y geométricas;
- validación;
- regeneración paramétrica.
