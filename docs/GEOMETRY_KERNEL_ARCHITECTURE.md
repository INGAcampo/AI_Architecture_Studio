# AMP-010B — AIAS Geometry Kernel

Capabilities:

- 2D points, vectors, lines, circles and bounding boxes
- polygon area, perimeter, centroid, containment and bounding box
- translation, rotation, scaling and transform composition
- line-line and line-circle intersections
- angles, projections and distances
- JSON geometry serialization
- geometry validation
- permanent reference cases
- QA evidence, technical file and release builder

This kernel is shared infrastructure for ECF, CAD, BIM and Engineering Capability Packs.
