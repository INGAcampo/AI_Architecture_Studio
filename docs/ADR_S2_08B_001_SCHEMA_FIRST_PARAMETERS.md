# ADR S2.08B-001 — Parámetros definidos por esquema

**Decisión:** todo parámetro debe partir de una `ParameterDefinition` estable.

**Motivo:** garantizar tipo, unidad, alcance, acceso, validación y persistencia coherentes.

**Consecuencia:** los objetos BIM registran esquemas reutilizables y las interfaces se
generan a partir de ellos.
