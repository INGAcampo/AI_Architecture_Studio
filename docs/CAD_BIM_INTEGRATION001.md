# CAD-BIM-INTEGRATION-001

This bridge projects stable, attributable BIM element footprints into the canonical Enterprise Drawing Framework. The neutral interchange contract uses millimetres, preserves element-to-entity mappings, discloses unsupported semantic losses and provides integrity-checked JSON round trips.

Property synchronization is non-mutating: only allowlisted fields become a proposed change set, and transaction commit plus professional review remain mandatory. This release intentionally does not claim full IFC conformance.
