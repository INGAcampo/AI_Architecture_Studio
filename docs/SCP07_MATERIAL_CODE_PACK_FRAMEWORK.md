# SCP-07 — Concrete, Steel and Foundation Code-Pack Framework

Define cobertura mínima y trazabilidad por regla para hormigón, acero y cimentaciones. Un paquete no puede declararse completo si omite resistencia, estabilidad, servicio, detallado, durabilidad, conexiones, asentamiento o requisitos sísmicos aplicables. Cada regla enlaza fuente autorizada, localizador, implementación, prueba y unidades; además se exige benchmark y revisión independiente.

La infraestructura está implementada. Las reglas oficiales permanecen pendientes de acceso legítimo, jurisdicción y verificación profesional.
