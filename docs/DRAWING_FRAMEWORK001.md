# DRAWING-FRAMEWORK-001

The Enterprise Drawing Framework defines a UI-independent canonical sheet model using millimetre paper space, stable entity IDs, named layers, bounded views, explicit scales, dimensions, title identity, revision and provenance. Deterministic exporters produce JSON, SVG, ASCII DXF and vector PDF with SHA-256 evidence.

The immediate consumer is an A3 foundation plan for LIGHTHOUSE-001 sourced from ECP-000001D. It is marked reference-only and requires professional review. The framework provides drawing production infrastructure; it does not itself authorize construction documents.
