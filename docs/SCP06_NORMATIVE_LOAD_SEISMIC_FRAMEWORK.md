# SCP-06 — Normative Load and Seismic Framework

Infraestructura para instalar paquetes legítimos de cargas y sismo con identidad, edición, editor, licencia, procedencia, jurisdicción, fechas de vigencia, combinaciones y parámetros sísmicos. Un paquete demostrativo, vencido, no aplicable o sin licencia nunca habilita una declaración normativa.

Esta macroentrega implementa el contrato y sus controles; no reproduce ni afirma implementar cláusulas protegidas de normas oficiales.
