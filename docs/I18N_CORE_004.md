# I18N-CORE-004 — Inspector BIM y Workspace

Esta entrega amplía la internacionalización verificable de AIAS a entidades BIM, catálogos, inspector, navegador de proyecto, paneles de Workspace, validaciones de docking Qt y etiquetas del esquema de muros.

No altera identificadores BIM, cálculos, geometría, comportamiento de Qt ni designaciones oficiales de normas. La cobertura sigue registrando brechas; no se declara una interfaz totalmente traducida.

Resultado auditado: 113 candidatos de texto fijo y 166 referencias de claves. La siguiente fase abordará el árbol visual BIM y controles restantes del Workspace.
