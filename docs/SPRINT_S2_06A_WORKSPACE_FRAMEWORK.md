# Sprint S2.06A — Workspace Framework

## Objetivo
Crear el núcleo no visual y comprobable del espacio de trabajo profesional de AIAS.

## Entregables
- `WorkspaceManager`
- `DocumentSession`
- `WorkspaceState`
- `PanelRegistry`, `PanelManager` y `DockManager`
- `LayoutManager` y persistencia JSON atómica
- Eventos del Workspace
- Integración opcional con Live Data Graph
- 20 pruebas automatizadas

## Alcance
Este sprint define contratos y estado. El acoplamiento visual con `QDockWidget`,
arrastre, pestañas y auto-hide gráfico se implementará de forma incremental en S2.06B.
