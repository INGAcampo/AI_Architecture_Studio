# CERTIFICATION-MASTER-PLAN-001

AIAS adopta CMMI-DEV V3.0 Nivel de Madurez 5 como objetivo oficial de madurez organizacional y CMMI AIM como extensión obligatoria de inteligencia artificial.

El sistema integrado de gestión se prepara para ISO 9001, ISO/IEC 27001, ISO/IEC 42001 e ISO 22301. Las certificaciones ISO y las calificaciones CMMI serán decisiones externas; los controles, pruebas y evaluaciones internas de AIAS solo representan preparación.

ISO 9001 se implementa usando la edición publicada vigente y una ruta de migración controlada hacia la edición 2026. ISO 22301 se mantiene bajo vigilancia normativa porque su siguiente edición está en desarrollo.

No se almacenan copias no autorizadas de normas o contenido CMMI. Para construir matrices cláusula por cláusula será necesario adquirir acceso legítimo a los textos normativos aplicables.
