# MEGABLOCK-GEOMETRY-2.0-A

Este megabloque es el propietario de la geometría matemática profesional de AIAS. OCCT/Open CASCADE se incorpora como backend aislado; no se mezcla con la responsabilidad semántica de IFC ni con el motor normativo estructural.

El contrato se activa antes de instalar el runtime. La disponibilidad, la licencia de distribución, la compatibilidad de bindings, los casos geométricos, las tolerancias y el rendimiento son gates independientes. Si OCCT no está disponible, AIAS mantiene su contrato nativo y falla de forma explícita, sin afirmar capacidad de producción.

El siguiente punto de integración será `GEOMETRY-BIM-BRIDGE-001`, después de que Geometry 2.0-A supere sus gates técnicos.
