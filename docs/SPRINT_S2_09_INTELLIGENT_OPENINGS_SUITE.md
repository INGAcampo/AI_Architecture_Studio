# Sprint S2.09 — Intelligent Openings Suite

## Objetivo
Incorporar puertas, ventanas y huecos genéricos vinculados de forma inteligente a muros.

## Capacidades
- Door, Window y Generic Opening.
- Posición relativa sobre muro.
- Antepecho y altura de dintel.
- Validación geométrica.
- Detección de colisiones.
- Relaciones host/opening.
- Supresión.
- Cantidades netas y volumen descontado.
- Reposicionamiento relativo al cambiar longitud del muro.
- Integración con Regeneration Engine.
- Eventos.
- Ejemplo funcional.
- 120 pruebas automatizadas.

## Resultado esperado
120 pruebas específicas y 1.090 acumuladas.
