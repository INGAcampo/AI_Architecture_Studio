# Sprint S2.08B — Parametric Engine

## Objetivo
Crear el sistema tipado de parámetros de AIAS para objetos BIM, CAD y de análisis.

## Capacidades
- Parámetros de instancia, tipo y compartidos.
- Acceso editable, solo lectura y calculado.
- Tipos numéricos, booleanos, texto, enum, material y referencia.
- Unidades y conversiones.
- Validación de rango.
- Colecciones por propietario.
- Registro global de definiciones.
- Persistencia JSON.
- Eventos de cambio.
- Integración con History Engine.
- Esquema inicial para Wall.
- Ejemplo funcional.
- 120 pruebas automatizadas.

## Resultado esperado
120 pruebas específicas y 730 acumuladas.
