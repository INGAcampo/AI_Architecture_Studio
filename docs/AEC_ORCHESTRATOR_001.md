# AEC-ORCHESTRATOR-001

El orquestador proporciona un lifecycle uniforme para workers AEC especializados. AIAS conserva el Project Graph, la trazabilidad y la validación; cada producto externo se trata como runtime opcional, no como dependencia implícitamente disponible.

El registro actual es declarativo. Ningún worker se presenta como integrado en producción hasta superar descubrimiento de runtime, API, licencia, fixtures y validación de resultados.
