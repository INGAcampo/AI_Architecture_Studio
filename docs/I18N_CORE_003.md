# I18N-CORE-003 — Ventana principal y nuevo proyecto

Menús, estados CAD, indicaciones, paneles, capas, asistente, barra de estado y creación de proyectos consumen ahora catálogos regionales. Los nombres oficiales ACI, AISC, ASCE, Eurocode, NSR, NEC, CIRSOC y NTC se conservan como designaciones técnicas.

La deuda medida bajó de 218 a 163 candidatas y las claves referenciadas aumentaron de 45 a 117. La cobertura completa no se declara; la siguiente fase aborda modelos BIM, Inspector y paneles de Workspace.
