# Sprint S2.05A — BIM Object Model Foundation

Introduce una base BIM aditiva y desacoplada bajo `engines.bim.object_model`.

Incluye identidad persistente, tipos y estados de objeto, propiedades, materiales,
relaciones dirigidas, revisiones y snapshots inmutables.

El sprint no reemplaza los modelos arquitectónicos existentes. Proporciona una
capa común para su migración gradual en S2.05B y posteriores.
