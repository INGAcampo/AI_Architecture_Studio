# W2-07 — Campaña de evidencia de usabilidad

La infraestructura está lista para registrar cinco sesiones representativas reales. Cada registro exige facilitador, código de participante, consentimiento, tareas, observaciones y artefactos; se encadena mediante SHA-256. La campaña no se considera completa hasta alcanzar cinco registros verificables y no se generan sesiones sintéticas.
