# SCP-03 — Whole-Building Analysis Contract

Contrato neutral entre el edificio estructural canónico y cualquier solver interno o adaptador CAE gobernado. Registra identidad y versión del solver, tipos de análisis, casos y fuentes de carga, demandas por elemento, advertencias y correspondencia exacta entre solicitud y resultado.

El contrato admite análisis lineal, modal, espectro de respuesta, segundo orden y no lineal como categorías de intercambio. La presencia de una categoría no afirma que todos los algoritmos estén implementados ni validados. Ningún resultado declara cumplimiento normativo por sí mismo.
