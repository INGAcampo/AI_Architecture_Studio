# CAPABILITY-FACTORY-001

The Capability Factory turns approved, traceable blueprints into reusable certified AIAS capabilities through `DEV-PLATFORM-001`. Its persistent registry permits only the sequence DRAFT → APPROVED → MATERIALIZED → VALIDATED → RELEASED and requires evidence at every gate.

Blueprint identity is immutable. Each production run compiles a specification, delegates to the governed development platform, retains normalized certification evidence and publishes a release event. Validation records the professional-review boundary; factory certification does not substitute for jurisdiction-specific engineering approval.
