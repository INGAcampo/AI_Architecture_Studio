# INTELLIGENCE-CORE-001

The Engineering Intelligence Core produces bounded recommendations only from identified evidence with integrity digests and trust scores. Required-claim coverage, conflicts, risk-dependent confidence thresholds and abstention are deterministic and auditable.

The reference consumer executes real admitted AEKS bearing-pressure knowledge, compares it against a governed reference using differential validation, and confirms EKG context. Even a high-confidence result is only a recommendation for licensed professional review, never a regulated approval.
