# AIAS NEXT — Ruta industrializada hacia la plataforma AEC

AIAS NEXT formaliza la estrategia aprobada para avanzar mediante una fábrica de desarrollo y megabloques paralelos gobernados.

## Orden de ejecución

1. Auditar y congelar el Golden Baseline cuando el estado reproducible lo permita.
2. Expandir la AIAS Development Factory con grafo de dependencias, pruebas dirigidas, integración segura y releases verificables.
3. Ejecutar Geometry 2.0, BIM Native 2.0 y Structural Platform como líneas paralelas con contratos explícitos.
4. Separar y versionar Standards Engine y jurisdicciones.
5. Formalizar workers AEC externos mediante un contrato común.
6. Incorporar agentes de ingeniería únicamente sobre servicios deterministas ya validados.

El baseline actual se registra como candidato, no como versión congelada, porque existen cambios pendientes en el árbol de trabajo. Esta decisión preserva la honestidad de la evidencia y evita certificar un estado que aún no es inmutable.

EXP-COMMS-001 y W2-07 permanecen fuera del camino crítico conforme a sus gates actuales.
