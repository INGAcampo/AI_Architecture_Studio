# S2.109 — Constraint Solver Engine

Motor de restricciones geométricas y paramétricas para AI Architecture Studio.

## Capacidades

- Variables con límites y bloqueo.
- Restricciones de valor fijo.
- Igualdad entre variables.
- Límites mínimos y máximos.
- Distancias geométricas 2D.
- Resolución iterativa por proyección.
- Validación de restricciones.
- Reporte de violaciones.
