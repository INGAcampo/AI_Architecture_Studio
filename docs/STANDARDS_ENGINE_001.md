# STANDARDS-ENGINE-001

El Standards Engine separa reglas, unidades, límites, referencias, jurisdicción y vigencia del resto de AIAS. El paquete venezolano inicial es únicamente un shell de trazabilidad: no contiene reglas normativas y no puede utilizarse para afirmar cumplimiento.

Una regla solo podrá evaluarse como capacidad normativa después de registrar fuente autorizada, implementación, casos de validación y revisión profesional independiente.
